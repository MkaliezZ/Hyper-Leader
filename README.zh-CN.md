# Hyper Leader

[English](README.md) | **简体中文**

基于**官方 DeepSeek Harness（DSH）运行时**的老板专项 Bot，按 Hyper Protocol 分离判断、功能与资产责任。前端依据用户提供的工作台与“添加信息来源”参考图实现；不是四个机器人、ERP 或通用编程助手。

**公开仓库只包含应用源码及运行文档。** 四个原始业务包、私有协议快照、内部规划／交接、凭据、业务资料与运行数据均不包含在内。全新克隆可启动界面和基础来源管理；四域方法及完整协议导出需要另行恢复获准的固定版本输入，缺失时不会冒充可用。公开源码不等于已授予整个项目开放源码许可。

## 启动

当前环境需要 Node.js **24.9+**、npm、Python **3.11+**。本机已在 Node 25 / Windows 上执行检查，其他平台仍需对应环境验收。

```sh
npm ci --ignore-scripts
npm run setup
npm run build
npm start
```

打开 **http://127.0.0.1:3220**。Windows 也可双击 `start.cmd`，macOS/Linux 使用 `bash start.sh`。仅监听回环地址，不要直接转发到公网或当作多租户服务。

1. 创建企业、个人或家庭空间，再建立一个事项。
2. 在“设置”填写**本项目**的模型地址、模型名和 Key。协议为 **DeepSeek Messages**；默认地址不是 OpenAI Chat Completions 地址。可以显式使用 `HYPER_LEADER_API_KEY` 环境变量，不读取其他项目或宿主的通用 DeepSeek Key。
3. 上传资料，或手动添加网页、网站栏目、RSS、文件来源。`保存`不读取，`保存并检查`才发起检查；正文、附件与资格分别记录。
4. 回到工作台提问。需要报告时要求保存，或点击“形成报告”；实际文件出现在“报告与版本”。
5. 继续修改会保存新版本；“确认此版本”只记录当前用户对该版本的认可，不等于专业审定或现实有效。

配置保存不触发模型请求。模型分析会发送所需文本、允许的来源和方法给所配置服务，可能产生费用；“测试已保存连接”也要经用户明确确认才发送一次最小请求。

步数与输出限制约束根代理的执行，不是精确金额或所有底层 HTTP 尝试的费用封顶；DSH 的重试、压缩等底层策略可能额外发起请求。连接检查也是一个检查动作，不承诺网络层绝无重试。请按服务商实际计费与已授权预算使用。

## 已实现的范围

- 参考图布局、六个入口、来源抽屉及窄屏适配。
- 主体／事项分隔、SQLite 事务和历史版本、本机私有文件与内容指纹。
- 手动来源的登记、检查、预览、描述修订、刷新、暂停、移除和本轮采用；失败不覆盖上次成功快照。
- 有限的网页正文／栏目链接／RSS发现与附件线索；禁止本机、内网、保留地址及不允许的重定向；公开页面不被自动认证为官方或可申报。
- PDF、DOCX、XLSX、CSV、TXT、MD 解析；保留原件及定位。扫描／加密或超过预算的资料如实报告，不假装已读全文。
- 四包的只读方法缓存、按任务读取、原市场校验／渲染、企业条件和窗口预筛、国内岗位渲染、海外双评分及渲染。原始 ZIP 和业务评分不改写。
- 官方 DSH 会话、受限 `leader_*` 工具、实际报告写入、取消、问题回答及恢复。资料采用范围或关键上下文变化时创建新 DSH 会话，旧日志保留，避免沿用已撤回的资料权限。
- Markdown／安全 HTML／原领域完整导出、版本与明确人工确认、行动和实际反馈、按原 schema 导出任务记录。
- 明确配置后，只在应用运行期间按预算刷新来源；不默认创建订阅，不自动调用模型、注册、申报或发布。

任务记录按实际方法文本、源版本、指纹和权限快照绑定。原脚本执行确定性检查；综合专业判断仍待评议。不会因 schema 或工程检查通过，就自动写 `meets_conditions`、人工通过或现实有效。

## 输入方法包

业务方法不是在全局安装 Skill。应用核对用户提供的四个 ZIP 指纹后，在自己的私有目录建立方法缓存。它需要当前项目已有的：

```text
30-业务资料库/00-原始材料与研究输入/原始包/
30-业务资料库/00-原始材料与研究输入/来源快照/Hyper-Protocol-v0.2-agent-draft-20261108/
```

缺少原始包时会显示方法不可用；请向项目所有者取得获准输入并核对 `src/judgment/policy.ts` 中的版本和 SHA-256，不把装上程序当作已拥有外部 Skill、账号、私库或师资。原协议基线为 `HP-0.2-AGENT-DRAFT-20261108` / `0.2-draft`，不自动下载、公开或替换为后来版本。

## 实际边界

- **动态网页／登录页面**：当前会标注需浏览器、需登录或失败，不代登录、绕过验证。可以上传有权使用的正文补充。
- **公网搜索**：默认未启用，仍可读已给 URL 与官方入口。在设置中可明确启用 Bing 公开 RSS 页面；它不是有稳定性承诺的开发者 API，失败和有限范围会保留。搜索摘要不能当作原文。
- **全国与跨国**：没有丰台白名单，按企业和目标法域找来源；目录不等于全球完整覆盖或当地资格成立。
- **文件资源**：单文件20 MiB、最多300页 PDF、受限 Office 解压／单元格预算；超出时拒绝或注明部分。XLSX 只读缓存值，不执行公式；空缓存不等于零。
- **移除／暂停**：停止后续使用和相关运行，不表示删除全部历史正文。用户需要清除数据时，应先停止应用并按明确保管／撤权范围处理私有目录与备份，不宣称自动完成所有个人信息识别或擦除。
- **调度**：当前是程序内来源刷新，不是操作系统守护服务；退出程序不会继续离线执行。默认手动，最多每轮5个读取，具体订阅预算可更低。
- **原领域数据**：内部交接与上游导出可能含当前本机资产定位及业务数据，公开分享前必须去敏并核许可。上传资料的 source URL 可由 `asset_ref` 在宿主内安全绑定，不允许模型传任意本机路径。

## 预览与验证

`/design-preview` 是明确标注“概念设计·示例数据”的**视觉参考页**，不读业务数据库、不发模型请求、不实际保存。正式 `/` 不自动填充示例企业、对话、收入或分数。

```sh
npm run check
npm run test:public
npm run build
```

以下完整回归需要本机获准的四包及协议快照；它们不会从公开仓库下载：

```sh
npm test
npm run test:runtime
npm run test:e2e
npm run doctor
```

- `test:runtime` 使用真实官方 DSH 进程和实际工具桥，但外部模型由本机确定性协议夹具替代；不产生外部模型费用。
- 浏览器检查在私有测试数据目录运行，网络／模型使用标注的合成夹具，验证操作和真实文件保存，不证明真实模型内容质量。
- Windows 浏览器测试优先使用已安装 Edge 的独立临时测试配置，不导入日常浏览器资料。无可用浏览器时 `npm run setup:browser` 可下载 Chromium headless shell 到 `.local/browsers`；不下载模型权重。
- 技术测试、自动截图审阅、原包回归、人工验收和真实经营结果分别报告，详见后续实际验收记录。

## 私有数据与配置

默认数据目录为 `.local/`，可用 `HYPER_LEADER_HOME` 显式更改；`HYPER_LEADER_PORT` 更改本机监听端口；`HYPER_LEADER_PYTHON` 仅用于显式指定兼容解释器。程序不自动读取 `.env`，不能只复制 `.env.example` 就认为已生效。

不要提交 `.local`、`.venv`、Key、真实文件、会话或日志。保存的 Key 以本机密钥加密，抵御的是误泄露，不抵御控制同一系统账户的人。已知配置凭据样式对模型视图脱敏，但不保证自动识别用户资料中的全部敏感信息。详见 [SECURITY.md](SECURITY.md)。
